# Ironclad Construction — marketing site

Single-page marketing site for a commercial / residential / industrial builder.
Vite + React + TypeScript + Tailwind + shadcn/ui.

```bash
npm install
npm run dev     # http://localhost:8080
npm run build
npm test
```

Company details (phone, email, address) live in `src/lib/company.ts`.
The estimate form is a simulated submit — wire it to a backend before launch.
